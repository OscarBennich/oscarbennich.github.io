# Personal Site Plan

## Overview
A personal portfolio and blog site for a software engineer, built with React and Tailwind CSS, hosted on GitHub Pages.

## Tech Stack
- **Framework**: React
- **Styling**: Tailwind CSS
- **Build Tool**: Vite (for fast development and optimized builds)
- **Hosting**: GitHub Pages
- **Deployment**: GitHub Actions (automated)

---

## Milestone 1: Basic Infrastructure ✅
**Goal**: Get a minimal React site building and deploying to GitHub Pages

### Tasks:
1. Initialize React project with Vite
2. Install and configure Tailwind CSS
3. Create a single "Hello World" page
4. Configure Vite for GitHub Pages deployment
5. Set up GitHub Actions workflow for automated deployment
6. Verify site is accessible at `https://oscarbennich.github.io`

### Deliverables:
- Working React + Tailwind build pipeline
- Deployed site on GitHub Pages
- Automated CI/CD via GitHub Actions
